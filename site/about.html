Project briefing

About Remote Command

Remote Command is a free, browser-based artillery game about careful aim, changing wind, and making the terrain work for you.

What this is

Remote Command is an independent web game project published at rc-9.com. It runs in a modern browser with no download, account, or purchase required. Each match combines turn-based artillery with destructible terrain, multiple environments, and a broad weapon system.

Play anywhere

Start a match directly in your browser on desktop or mobile. The game includes touch controls alongside keyboard controls.

Learn the system

Wind, angle, power, terrain, and weapon behavior all matter. The how-to-play guide explains the controls and modes.

Built as a project

The game is actively maintained as a standalone web project. Features and balance may change as the project develops.

How the site is supported

Remote Command is free to play. Advertising may appear in designated areas such as the title screen, end-of-round report, and informational pages; ads are not intended to cover active gameplay. Advertising and measurement are described in the Privacy Policy.

Questions and feedback

Found a bug, have a gameplay suggestion, or need to ask about the site? Use the contact page. We welcome clear reproduction steps and the browser/device information that helps us investigate.
